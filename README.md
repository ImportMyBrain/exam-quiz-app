# exam-quiz-app

一个 Claude Skill：把课程复习资料（PPT、PDF、Word、考试大纲）做成**离线刷题软件**（单个 HTML 文件 + 在线版）。

## 它会做什么

- **严格按原资料出题**：题型、题号、原文、答案都不改，不自己加题；发现资料有错只加“注”。
- **每题都有解析**：选择题说明为什么选；计算题零基础详解（概念 → 分步算式 → 必背公式）；简答题给精简采分点。
- **刷题功能**：按题型分页、章节掌握度、考试倒计时、错题本（本地保存）、打乱顺序、只练错题。
- **搜题**：Ctrl/⌘+K 按关键词实时搜题干、选项和答案。
- **全键盘操作**：Ctrl/⌘+Enter 显示答案，再按一次下一题；选择题按 1–4 作答，回车下一题。
- **简答沉浸模式**：一次一题，Enter 对照答案并标出命中的关键词。
- **模拟考试**：从原题随机组卷、计时、自动判分。
- **额外练习**：按原题题型随机出数字的同类题，并标明“不是原题”。
- 支持手机和深色模式。

## 安装

**claude.ai / Claude 桌面版**：下载 `exam-quiz-app.zip`，在 设置 → Capabilities → Skills 里上传。

**Claude Code**：把 `exam-quiz-app/` 文件夹复制到 `~/.claude/skills/` 下。

## 使用

把复习资料发给 Claude，说“帮我生成刷题软件”或“生成期末复习题库”即可。
