# 期末刷题软件制作流程

用户发来某门课的复习资料，要求生成刷题软件或题库时，按以下流程做。

## 1. 读资料
- .pptx / .docx：解压后解析 XML，标出高亮（highlight）和彩色文字，提取全部图片逐张查看。
- .doc：先用 soffice 转成 .docx 再解析；内嵌 .wmf 公式转成 PNG 查看。
- 扫描版 PDF（没有文字层）：用 pdftoppm 渲染成图片逐页看，看不清的局部放大。
- 先确认资料类型：标高光的是答案 / 已附答案 / 只有大纲。

## 2. 题目原则（最重要）
- 严格按资料：题型、题号、题目原文、答案都不改，不自己加题。资料里的填空就做成填空，不擅自改成选择。
- 只有大纲、没有题时，才按大纲知识点出题，并在回复里说明哪些是编的。
- 逐题核对资料答案（计算题实际算一遍）。发现错误或歧义时不改答案，在解析里加“注：……”，回复里列出。不确定的地方不要“纠正”，以资料和考试约定为准（例如屏蔽位 1 表示开放还是屏蔽，要看题目的约定）。
- 每题都写解析：选择题说明为什么选、其他选项错在哪；计算题写零基础详解（概念白话解释 → 分步算式 → 必背公式）；简答/概念题写精简采分点（关键词加粗），资料原文折叠在下面。

## 3. 软件功能（单个 HTML，离线可用）
- 页面：按题型分页（填空 / 选择判断 / 简答 / 计算 / 模拟考试 / 额外练习 / 搜题 / 错题本），资料里没有的题型不显示。
- 顶部：考试倒计时（日期可设置）、整体练习进度（大号百分比 + 进度条）、按章节显示掌握百分比，可以按章节筛选；手机上收起章节小进度条，避免吸顶区域太高。
- 右上角“外观”切换：跟随系统、白天、黑夜，以及几种纯色和撞色配色（如护眼米黄、抹茶绿、樱花粉、深海蓝、紫夜、黑黄撞色、纯白/纯黑极简）；全部用 CSS 变量实现，选择存 localStorage。系统深色规则只在没选主题时生效（:root:not([data-theme])）。
- 错题本：答错、看答案、自评“没会”的题自动进入；做对后移出。记录存在 localStorage（读写都要 try/catch）。
- 打乱顺序、只练错题。
- 搜题：Ctrl/⌘+K 打开，按关键词实时搜题干、选项和答案，结果直接显示答案，点击跳到原题。
- 全键盘操作：
  - Ctrl/⌘+Enter 显示答案，再按一次进下一题；
  - 看答案后光标回到第一个空；
  - 选择题按数字键作答（多选题数字键勾选、回车提交），回车或 → 下一题；
  - 填空回车跳到下一个空。
- 填空：默写和背诵（遮挡点开）两种模式；判分宽松，接受同义写法和符号的键盘写法（φ→∅、v→∨、>=→≥ 等）。
- 选择判断：单选、多选（多选少选错选都算错）、判断题可按题型筛选。
- 简答：列表模式 + 练题模式 + 背题模式（不再单独做沉浸模式）；Enter 对照答案，Shift+Enter 换行，注意 isComposing 避免输入法回车误触发；对照时标出命中的关键词。
- 练题模式和背题模式（选择判断、简答都要有），像背单词软件一样一屏一题：
  - 练题模式：直接作答；答错标红并显示答案和解析，按 → 或“下一题”继续；错题隔 3 题再出现，直到答对；错过的题答对后隔 8 题再出现一次确认；第一次就答对的本轮不再出现。
  - 背题模式：新题先显示答案和解析，按 → 后变成作答界面；没答对的按练题模式的规则反复出现。
  - Ctrl/⌘+Enter 或“不会”按钮算答错并显示答案；简答按关键词自动判定，可手动改判。
  - 题目上方显示本轮大号百分比和进度条（已掌握 / 待复习 / 未做）；底部显示本轮题号格子（绿=已掌握、红=待复习、框=当前），点题号可以先做那道。
  - 都带“打乱顺序”（只打乱本轮剩下的题，不丢进度）和“只练错题”（打开时冻结错题名单，做对后不会被移出本轮）。
  - 进度存 localStorage；一轮结束列出做错过的题，可以只练这些题再来一轮。
- 计算：原题解答 + 零基础详解 + 必背公式。
- 模拟考试：全部原题随机组卷，计时；交卷后选择题自动判分，简答按关键词估分，计算题看答案后自评；错题进错题本。
- 考试预测：单独一页 + 顶部标签“预计 xx 分 · 能否通过”。按试卷各题型分值，每道题按练习记录估算得分概率（掌握 / 做错 / 没做三档），给出预计得分、可能区间、通过结论（稳过 / 有风险 / 有希望 / 暂时过不了）、各题型预计得分和提分最快的题型（带“去练”跳转）；有完整打分的模拟考试时，把最近几次平均分按一定权重并入；及格线可改；注明只是估计。
- 额外练习（可选）：按原题题型随机出数字的同类题，答完给出步骤；必须标明“不是原题”，并和原题分开放。
- 适配手机，支持深色模式；同一页面里不同分页的元素 id 不要重复。

## 4. 检查与交付
- 用 Playwright 点一遍：每个分页、快捷键流程、搜题、模拟考试交卷、每类随机题跑多次无报错；截图看一次手机宽度的效果；练题、背题模式要验证错题隔几题重新出现、确认后完成、刷新后进度保留。
- 交付：用 SendUserFile 发完整的 .html 文件（加上 doctype/head），同时用 Artifact 发布在线版。
- 回复里写清：收录了哪些题、答案核对发现的问题（只加注，不改答案），以及按用户剩余时间给出的复习顺序。
- 用户只要求改某一门课时，不动其他刷题本。
